# FasalRaksha — फसल रक्षा 🌾

AI-powered crop disease detection for Indian farmers.

## What it does
- Upload a crop photo → AI detects disease + severity
- Treatment advice in 8 Indian languages (Hindi, Marathi, Punjabi, Telugu, Kannada, Gujarati, Odia, English)
- Chemical + organic remedy recommendations with cost estimates
- Works on any device, no app download needed

## Tech Stack
- Vanilla HTML/CSS/JS
- OpenRouter AI API (vision analysis)
- Gemini AI model for multilingual advice

## Live Demo
[View on Netlify](fasalraksha.netlify.app)

## Setup
1. Get a free API key from [openrouter.ai](https://openrouter.ai)
2. Open `index.html` and replace `YOUR_OPENROUTER_KEY_HERE` with your key
3. Open in browser

## Built for
Indian farmers who need instant crop disease diagnosis in their own language.
